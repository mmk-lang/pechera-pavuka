# Печера павука

Браузерна 3D покрокова стратегія з видом згори. Автор ідеї та гейм-дизайнер — Коля.
Повний опис гри — у [TZ.md](TZ.md).

## Як запустити

Потрібен [Node.js](https://nodejs.org/) версії 20 або новішої.

```bash
npm install
```

```bash
npm run dev
```

Потім відкрий адресу, яку покаже термінал (зазвичай http://localhost:5173).

Інші команди:

- `npm test` — автоматичні тести (Vitest);
- `npm run build` — перевірка типів і збірка готової гри в папку `dist/`.

## Гра в інтернеті (GitHub Pages)

Після кожного `git push` у гілку `main` GitHub сам запускає тести, збирає гру й оновлює сайт
(див. `.github/workflows/deploy.yml`). Хід публікації видно на вкладці **Actions** репозиторію.
Адреса гри: https://mmk-lang.github.io/pechera-pavuka/

На телефоні гру можна додати на головний екран (Safari: «Поділитися» → «На екран Додому»;
Chrome: меню → «Додати на головний екран») — вона відкриватиметься на весь екран, як застосунок.

**itch.io або інший хостинг.** `npm run build` створює папку `dist/` з готовою грою. Усі шляхи в ній відносні,
тож достатньо запакувати вміст `dist/` у zip і завантажити як HTML-гру (на itch.io — «This file will be played in the browser»).

## Як грати

**Стартовий екран** коротко пояснює правила й дає вибрати:
- **печеру** — один із 6 рівнів або **випадкову**: генератор будує нову печеру з номера печери.
  Рівні: 1. Печера Колі, 2. Тісна нора (мала, 16 каменів), 3. Широка зала (широка, павук дивиться на всі боки),
  4. Гніздо в кутку (павук у лівому куті), 5. Пильні очі (ширші промені павука — найважче),
  6. Довгий тунель (довга печера, турель далеко від гнізда). Після перемоги кнопка «Далі» веде на наступний рівень;
- **номер печери (seed)** — порожнє поле означає випадкову печеру; той самий номер дає ту саму партію;
- **показувати наступну лінію павука** — вимкни для складнішої гри;
- **ризик клітинок** — над клітинками підписи «1 з 4», «75%»: імовірність, що клітинку бачитимуть вороги
  після «Кінця ходу» (павук і павучата разом);
- **підказки** — жовтий рядок «💡» у лівій панелі: що зробити зараз.

Налаштування й seed записуються в адресу сторінки (наприклад, `?seed=42&next=0&risk=1&hints=1&play=1`).
Таке посилання можна надіслати — друг отримає ту саму печеру. Оновлення сторінки починає цю саму печеру заново.
Після перемоги чи поразки: **«Нова печера»**, **«Ця сама печера ще раз»** або **«Меню»**.

**Мета:** зібрати в турелі 4 деталі (жовті шестерні) і патрон, привести туди солдата-оператора й вистрілити.
Що вже зроблено — видно на панелі «Мета» справа вгорі.

**Павук.** Гігантський павук сидить у гнізді й дивиться вздовж однієї з 5 ліній:
- **суцільний червоний клин** і **червоні кільця** — клітинки, які павук бачить зараз;
- **пунктирний клин** і **помаранчеві кільця** — куди він подивиться наприкінці раунду.
Солдат, що опинився під поглядом (навіть посеред ходу), одразу стає **коконом**. Клітинки за каменями павук не бачить.

**Павучата.** По печері бігають 6 павучат. Кожне бачить свою клітинку й ту, на яку показує **червона стрілка**
(ці клітинки теж мають червоні кільця). Наприкінці раунду кожне павуча перебігає на сусідню клітинку
й дивиться в новий бік — куди саме, заздалегідь невідомо. **Кинь предмет** (деталь чи патрон) у клітинку з павучам —
і воно загине, а предмет лишиться там. Убиті павучата не повертаються.

**Кокони.** Над коконом — лічильник 3 → 2 → 1. Якщо до кінця лічильника солдата не розмотати, він гине.
Вільний солдат у тій самій клітинці натискає **«Розмотати»** (1 AP) — врятований одразу має 3 AP.
Кокон можна також підняти й віднести в безпечне місце. Якщо не лишилось жодного вільного солдата — поразка.

**Керування:**
- Клік або тап по солдату (чи по його картці внизу, чи клавіші `1`–`4`) — вибрати його.
- Жовті клітинки — куди вибраний солдат може піти. Клік по жовтій клітинці — крок.
  Якщо клітинку бачить павук, гра попросить клікнути ще раз — щоб не потрапити в кокон випадково.
- Над вибраним солдатом з'являються кнопки дій (лише ті, що зараз можливі):
  **Підняти** (предмет, солдата чи кокон), **Кинути** (потім клік по помаранчевій клітинці; `Esc` — скасувати),
  **Розмотати**, **Вогонь!**
- Предмет, який принесли або кинули в клітинку турелі (синя), встановлюється сам.
- Кожна дія коштує 1 очко дії (AP), у кожного солдата їх 3 на хід. «Кінець ходу» (або `Enter`) — павучата перебігають, павук повертається, починається новий раунд.
- У клітинці можуть стояти не більше двох вільних солдатів (кокони, кого несуть, предмети й павучата місця не займають).
- Справа під метою — **список подій**: хто потрапив у кокон, кого врятували, кого вбили.
- **«↶ Скасувати»** (або `Backspace`, `Ctrl+Z`) — відкотити останні кроки, підняття й кидки цього ходу.
  Не скасовується те, що вже сталось у грі: кокон, убите павуча, розмотування, кінець ходу.
- Кнопка **«?»** ховає/показує легенду й керування (на телефоні спершу сховані), **«Меню»** — повернутись на старт.
- Seed партії видно дрібно в лівій панелі.

**Звук** — кнопка 🔊 / 🔇 у лівій панелі (браузер пам'ятає вибір). Усі звуки синтезуються в коді (`src/audio/sound.ts`),
окремих файлів немає. Гучність — `soundVolume` у `data/balance.json`.

## Де змінювати баланс і рівень

Усі числа гри лежать у JSON-файлах — код правити не треба. Після збереження файлу гра в браузері перезавантажиться сама.

- **`data/balance.json`** — правила й баланс: кількість солдатів, очки дій, кількість павучат, таймер кокона тощо (таблиця в розділі 10 ТЗ).
  Кількість сусідів кожної клітинки (`neighborsCount`) теж звідси — граф ходів перебудується сам.
  Розділ `camera` — налаштування камери: `pitchDeg` (кут нахилу), `minDistance` / `maxDistance` (межі масштабу), `panSpeed` (швидкість руху), `rotateSpeedDeg` (швидкість повороту).
  Розділ `generator` — налаштування генератора випадкових печер: кількість і розміри каменів, відступи,
  `maxLanesPerCell` (з якої кількості ліній максимум видно клітинку), `minSafeCells` / `minExposedCells`
  (скільки має бути безпечних і небезпечних клітинок). Генератор пробує знову, доки печера не пройде всі перевірки:
  граф зв'язний, кожна клітинка видима не більше ніж з двох ліній, біля кожної небезпечної клітинки є безпечна,
  старт і турель безпечні. Тести проходять 100 таких печер і ще 10 — до перемоги.
- **`data/level01.json` … `level06.json`** — рівні (список — у `src/levels.ts`, назви — у `uk.json`, розділ `levels`).
  Рівні 2–6 зроблені генератором, їх можна правити вручну так само, як перший:
  - `cave` — розміри печери й висота стін;
  - `rocks` — камені: `x`, `z` (місце на підлозі), `radius`, `height`;
  - `cells` — клітинки, де стоятимуть солдати; кожна прив'язана до свого каменя (`rockId`).
    `exposedTo` — з яких ліній павука видно клітинку. Якщо пересунути камінь чи клітинку,
    гра покаже червону помилку з правильним значенням — його треба вписати сюди;
  - `spider` — де гніздо павука, `lanes` — його 5 ліній огляду (кут і ширина клину);
  - `startCell`, `turretCell`, `items` — старт солдатів, турель, деталі й патрон.

Якщо в рівні помилка (наприклад, камені налазять один на одного або клітинка стоїть усередині каменя), гра покаже її червоним у лівому верхньому куті.

## Структура коду

```text
src/
  core/      правила гри без 3D: типи, граф клітинок, стан, rules.ts (validate / apply),
             visibility.ts (що бачить павук), spiderlings.ts (павучата), risk.ts (ризик клітинок),
             generator.ts (випадкові печери), rng.ts (випадковість із seed)
  render/    3D-графіка на Three.js (печера, камені, клітинки, солдати, павук, павучата, ефекти, камера)
  audio/     звуки (синтез через Web Audio)
  input/     миша, клавіатура й дотики
  ui/        написи поверх гри
  i18n/      усі тексти інтерфейсу (uk.json)
  game.ts    з'єднує все разом: дія гравця → перевірка → новий стан → картинка
data/        рівень і баланс
tests/       автоматичні тести
```
