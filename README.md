# Печера павука

Браузерна 3D покрокова стратегія з видом згори. Автор ідеї та гейм-дизайнер — Коля.
Повний опис гри — у [TZ.md](TZ.md).

## Як запустити

Потрібен [Node.js](https://nodejs.org/) версії 20 або новішої.

```bash
npm install
```

```bash
npm run dev
```

Потім відкрий адресу, яку покаже термінал (зазвичай http://localhost:5173).

Інші команди:

- `npm test` — автоматичні тести (Vitest);
- `npm run build` — перевірка типів і збірка готової гри в папку `dist/`.

## Керування камерою

| Дія | ПК | Телефон |
| --- | --- | --- |
| Рух | перетягнути мишею, WASD або стрілки | один палець |
| Масштаб | колесо миші, `+` / `−` | щипок двома пальцями |
| Поворот | Q / E | покрутити двома пальцями |

## Де змінювати баланс і рівень

Усі числа гри лежать у JSON-файлах — код правити не треба. Після збереження файлу гра в браузері перезавантажиться сама.

- **`data/balance.json`** — правила й баланс: кількість солдатів, очки дій, кількість павучат, таймер кокона тощо (таблиця в розділі 10 ТЗ).
  Розділ `camera` — налаштування камери: `pitchDeg` (кут нахилу), `minDistance` / `maxDistance` (межі масштабу), `panSpeed` (швидкість руху), `rotateSpeedDeg` (швидкість повороту).
- **`data/level01.json`** — сама печера:
  - `cave` — розміри печери й висота стін;
  - `rocks` — камені: `x`, `z` (місце на підлозі), `radius`, `height`;
  - `cells` — клітинки, де стоятимуть солдати; кожна прив'язана до свого каменя (`rockId`);
  - `spider` — де гніздо павука, `lanes` — його 5 ліній огляду (кут і ширина клину);
  - `startCell`, `turretCell`, `items` — старт солдатів, турель, деталі й патрон.

Якщо в рівні помилка (наприклад, камені налазять один на одного або клітинка стоїть усередині каменя), гра покаже її червоним у лівому верхньому куті.

## Структура коду

```text
src/
  core/      правила й дані гри, без 3D (типи, перевірка рівня)
  render/    3D-графіка на Three.js (печера, камені, павук, камера)
  input/     миша, клавіатура й дотики
  ui/        написи поверх гри
  i18n/      усі тексти інтерфейсу (uk.json)
data/        рівень і баланс
tests/       автоматичні тести
```
