# Проєкт «Печера павука»

Браузерна 3D-гра (вид згори, покрокова стратегія). Автор ідеї та гейм-дизайнер — Коля (14 років). Ти — розробник.

## Головне
- Повне ТЗ — у `TZ.md`. Читай його перед кожним етапом. Правила гри визначає Коля; усе, чого немає в ТЗ, — припущення, яке легко змінити.
- Стек: TypeScript + Vite + Three.js + Vitest. Без бекенду. Запуск: `npm run dev`.
- Нових залежностей, окрім three, vite, typescript, vitest, не додавай без погодження.

## Архітектура
- `src/core/` — чиста TypeScript-логіка без Three.js (стан, правила, ворог, seeded RNG, рівень).
- `src/render/` — Three.js: лише читає стан і малює.
- `src/ui/`, `src/input/`, `src/i18n/uk.json`.
- `data/level01.json`, `data/balance.json` — рівень і баланс (усі числа лише тут).
- Кожна дія — команда з валідацією; недопустима дія відхиляється з українською причиною.

## Стиль
- Код і назви — англійською, коментарі та інтерфейс — українською.
- Код простий і прокоментований: його буде читати підліток-початківець.
- Усі рядки інтерфейсу — в `i18n/uk.json`.

## Робота по етапах

- НЕ переходь до наступного етапу, доки автор не напише «далі».
